## 4. 实测中发现并修复的问题

1. **抽取 prompt 没给 JSON Schema**（真实模式才暴露）：prompt 只说「严格符合 JSON Schema」却没附 Schema，qwen3.7-plus 两次输出自造结构（meeting_date/attendees/…），zod 校验失败 → 降级规则抽取，浪费 ¥0.019968。修复：`lib/prompts/extract.ts` 附完整字段示例。修复后一次通过（6 议题/2 决议/5 待办），浏览器流水线确认落库成功，AI 标题、重复讨论提醒、冲突推翻建议均正常。
2. **查重阈值 0.8 在真实向量下漏报**：「PPT 要不要换回蓝白那版」对 11/12 决议余弦 0.7312 < 0.8。`DUPLICATE_THRESHOLD` **0.8 → 0.7**。6 句探针验证：真重复 0.7312 / 0.8656 / 0.8496 全命中且命中正确条目；非重复 0.6088（PPT 加动画）/ 0.5328 / 0.2897 全不命中。`REFUSE_VEC_THRESHOLD` 0.35 **不动**（拒答 9/9 全对，多数由证据闸门拦下）。
3. **证据闸门不认同义词**：「幻灯片用什么风格」被分词成「幻灯/片」，记录里只有 PPT → 误拒。`lib/rag/terms.ts` 加同义归一 幻灯片/幻灯 → ppt。
4. **问答 prompt 两条约束**：日期写绝对日期（如 11/24）；任务没负责人 ≠ 证据不足，应答「待认领」而非拒答（修复 p6 真实误拒）。
5. **eval 要点匹配忽略空白**：「10页」=「10 页」（测量口径修正，非改答案）。
