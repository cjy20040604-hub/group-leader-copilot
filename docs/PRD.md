# PRD：「组长减负」小组作业协作纪要工具

> 结构：问题 / 目标 / 非目标 / 用户故事 / 验收标准 / 指标（供后续 write-spec 迭代）
> 需求来源：`qoder-quest-prompt.md`（CEO 已批准默认决策）

> **v2 定位（2026-11-21）**：帮组长把会上说的话，变成「确认过的决定」「有人负责跟进的任务」和「下次会接着推进的记录」。用户需求与 AI 环节分析见 `docs/product-v2.md`（需求为假设 · 待验证）。

## 1. 问题

大学 5 人小组组长「林晓」本学期并行 3 门课小组作业（市场营销学 / 数据库原理 / 创新创业实践），组员：阿杰、小雨、浩然、思琪。

| # | 痛点 | 解法 |
|---|---|---|
| P1 | 开 1 小时会没人整理纪要 | 转写 → 结构化纪要（决议/待办/分歧/待定）→ 组长确认 → 一键复制群消息 |
| P2 | 3 天后开会不记得上次决议，重复讨论 | 会前简报 + 「问问上次」RAG 带出处问答 + 议程撞旧决议自动提示 |
| P3 | DDL 临近才发现没人催 | 看板 + 风险灯（规则代码）+ D-3/D-1/过期提醒 + 催办文案模板 |
| P4 | 3 门课进度全靠脑子装 | 首页「本周我要盯的事」跨课程 top 5 |

## 2. 目标

- 现场可跑通的 Demo：`npm i && npm run seed && npm run dev` 5 分钟内跑通，无 API Key（`MOCK_LLM=true`）全流程可演示。
- 从粘贴转写到可发群 ≤ 3 次点击。
- RAG 评估 Hit@8 ≥ 90%，问答带 [日期·类型] 出处，无证据拒答。
- 成本可见：每次模型调用写 usage_log，`/app/cost` 展示单次会议 / 问答 / 学期成本。

## 3. 非目标

登录注册、多租户、微信 / 短信推送（已做站内通知和浏览器通知，钉钉群机器人是下一步）、移动端原生 App、真实支付（套餐和额度已做，开通是演示）。实时 ASR 已接入（v2，百炼 qwen3-asr-flash），2026-11-21 用真实接口联调通过；离线模式下用演示录音模拟。

## 4. AI 边界（硬性）

| 环节 | AI? | 实现 |
|---|---|---|
| 开录 / 静音暂停 / 自动结束 | ❌ 规则（Auto） | 进会议室 3 秒倒计时、VAD 音量阈值、静音时长 |
| 语音→文字 | ✅ ASR | 百炼 Qwen-ASR（`ASR_MODEL`），只上传有人说话的段 |
| 会中「这事定过了」 | ✅ 仅 embedding + 关键词规则 | 规则挑句 → `findSameTopicDecisions`，不调大模型 |
| 转写→结构化纪要 | ✅ LLM 抽取 + 代码校验 | `lib/prompts/extract.ts` + zod + 人名/日期校验 |
| 上次决定问答 | ✅ RAG | 向量+BM25 → RRF → qwen-plus 带出处 |
| 重复讨论检测 | ✅ 仅 embedding | 相似度 ≥ 0.80 提示，不调 LLM |
| 会前简报 | ✅ LLM（可降级模板） | qwen-plus |
| 任务 CRUD / 看板 / 状态流转 | ❌ 代码 | 确定性 API |
| 组员认领 / 卡住 / 申请延期，组长确认 / 批延期 | ❌ 代码 | `lib/task-flow.ts` |
| 待我处理 / 带到下次会 | ❌ 代码 | `lib/review.ts` |
| DDL 计算 / 提醒调度 / 风险灯 | ❌ 代码 | `lib/risk.ts` + 扫描路由 |
| 催办消息 | ❌ 模板优先 | 固定模板 |
| 权限 / 导出 / 统计 | ❌ 代码 | — |

人在回路：所有 AI 产出标「AI 生成 · 待确认」，组长确认后才写 tasks / memory_items。

## 5. 用户故事

- US1（P1）作为组长，我粘贴会议转写，1 分钟内得到结构化纪要，逐条勾选确认后一键复制成群消息。
- US2（P2）作为组长，我问「我们PPT最后定的什么风格？」，得到「学校模板（原来定蓝白商务风，11/12 改的）」并附引用卡片可跳转高亮。
- US3（P2）作为组长，我填议程「PPT 风格」时系统提示 11/12 已有决议，避免重复讨论。
- US4（P3）作为组长，我点「时间快进 3 天」，浩然 ER 图任务变红并出现催办草稿。
- US5（P4）作为组长，我打开 /app 一屏看到 3 门课最紧急的那件事（可直接复制提醒），并能自己安排或删除会议；有组员跨课撞 DDL 时才提醒。
- US6（组员）作为组员，我切换身份后只看到自己的任务，能改状态、填一句进度。
- US7（付费人）作为付费决策人，我在 /app/cost 看到 1 小时组会的文字处理约 6 分 5、一个小组一学期模型成本约 2.2 元，以及按付费率和录音方式变化的回本组数。
- US8（v2 组长）作为组长，我进会议室不用按录音键：3 秒后自动开录，说的话实时变成文字，散会后纪要自动整理好等我确认。
- US9（v2 组长）作为组长，组员在会上提议改已经定过的事时，屏幕上当场提醒「这个 11/12 已经定了」。
- US10（v2 组员）作为组员，我在「任务与回顾」里点一下就能告诉组长：做完了、卡住了、想延期，或者认领没人管的任务。
- US11（v2 组长）作为组长，我只看「待我处理」：确认完成、批延期、处理卡点、催 48 小时没动静的；下次开会前「带到下次会」已经排好。

## 6. 验收标准（对应里程碑 M1–M6，详见 TASKS.md）

1. `npm run dev` 首页可见 3 门课与历史纪要（M1）。
2. 粘贴 `seed/new_meeting.txt` → 确认 → 任务出现在看板，≤ 3 次点击（M2）。
3. 问 PPT 风格答「学校模板」并说明从蓝白改过来；`npm run eval` Hit@8 ≥ 90%（M3）。
4. 快进 3 天浩然任务变红 + 催办文案；`risk.test.ts` 通过（M4）。
5. /app/cost 显示单次会议成本；落地页含 FAQPage JSON-LD 与 /llms.txt（M5）。
6. 三份文档 + README 完整；lint + typecheck + test 全绿（M6）。

## 7. 指标

- 演示指标：粘贴→可发群点击数 ≤ 3；纪要生成 ≤ 60s（Mock 即时）。
- 质量指标：Hit@8 ≥ 90%、引用准确率、拒答正确率（eval 输出）。
- 商业指标（docs/cost-model.md）：单次会议成本、单用户学期成本、纪要版（6.9 元）毛利率 ≈ 79.7%、专业版（14.9 元，含 8 小时实时转写）≈ 48.1%；7 成纪要版 + 3 成专业版时 69 个付费组回本。
- 待验证假设：组长付费意愿；老师为贡献度数据付费意愿；组员对被追踪的接受度。
