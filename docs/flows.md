# 用户流程清单（flows）

> 覆盖全部 8 个路由。每个页面按「入口 / 主操作 / 空状态 / 错误状态」写，供后续 workflow-audit 使用。
> 身份说明：顶部下拉可切换「组长林晓 / 组员（阿杰、小雨、浩然、思琪）」，不做账号体系。**组员身份差异在各页单独注明，汇总见文末。**

## 1. `/` 落地页

- **入口**：直接访问域名；搜索引擎 / AI 助手引用（语义化 HTML、FAQPage + SoftwareApplication JSON-LD、/llms.txt、/sitemap.xml）。
- **主操作**：
  1. 看一句话价值主张和「3 个痛点 → 3 个功能」；
  2. 浏览定价卡片（免费 / 组长 Pro 19.9 / 课程版）与 FAQ；
  3. 点「进入 Demo」→ 跳 `/app`。
- **空状态**：静态页，无数据依赖，不存在空状态。
- **错误状态**：无后端调用；若 Demo 服务未启动，「进入 Demo」跳转失败由浏览器兜底（无需专门设计）。

## 2. `/app` 本周我要盯的事

- **入口**：落地页「进入 Demo」；应用内导航首页；处理完会议后返回。
- **主操作**：
  1. 一屏看跨 3 门课的风险任务 top 5（红 > 黄，按 DDL 排序）；
  2. 看即将到来的会议与最新提醒（D-3 / D-1 / 过期）；
  3. 点任务卡 → 跳对应课程看板；点提醒的「复制催办文案」；点「新建会议」→ `/app/meeting/new`。
- **空状态**：没有任何风险任务时显示「本周没有要救火的事 🟢」+「新建会议」按钮；未跑 seed 时提示「先运行 npm run seed 加载演示数据」。
- **错误状态**：数据加载失败显示重试按钮；提醒扫描失败不阻塞页面，标注「提醒数据可能滞后」。
- **组员差异**：top 5 只统计自己的任务；不显示「新建会议」入口；提醒只显示与自己相关的。

## 3. `/app/c/[courseId]` 课程页（三 Tab）

- **入口**：`/app` 点课程或任务卡；侧边导航选课程。
- **主操作**：
  1. **纪要列表 Tab**：按日期倒序浏览历史会议，点一条 → `/app/meeting/[id]`；可点「生成会前简报」（上次决议 + 未完成待办 + 遗留问题，≤200 字，标「AI 生成 · 待确认」）；
  2. **任务看板 Tab**：四列（待认领 / 进行中 / 待审核 / 已完成），拖拽卡片改状态；卡片显示负责人、DDL、风险灯、最近更新时间；「待认领」任务可点认领；
  3. **问问上次 Tab**：输入问题 → 带 [日期·类型] 出处的回答 + 引用卡片，点卡片跳纪要详情并高亮 evidence。
- **空状态**：纪要列表为空 →「这门课还没开过会，去新建会议」；看板为空 →「确认一份纪要后任务会自动出现在这里」；问答未提问 → 推荐问题示例（如「我们PPT最后定的什么风格？」）。
- **错误状态**：courseId 不存在 → 「课程不存在」+ 返回首页；拖拽保存失败 → 卡片回弹原位并提示重试；问答检索不到（相似度 < 0.35 且关键词无命中）→ 「记录里没找到」+「加入下次会议议程」按钮（这是正常拒答，不算故障）；LLM 超时 → 提示重试，Mock 模式不受影响。
- **组员差异**：看板只显示自己的任务，只能拖自己的卡；纪要列表和问答全组可见（记忆是共享的）；无「生成会前简报」权限。

## 4. `/app/meeting/new` 新建会议（9 步流水线）

- **入口**：`/app` 或课程页的「新建会议」按钮。仅组长可见。
- **主操作**（对应步骤条，每步显示耗时与 token 花费）：
  1. **输入**：粘贴转写（演示用 `seed/new_meeting.txt`）或上传音频（标「Demo 模拟」）；选课程（3 门演示课 + 自建课程/小组）、会议日期；标题可手填，留空则由 AI 从抽出的议题建议；可选填「本次议程」；
  2. **议程重复检测**（填了议程才触发）：每条议程做 embedding，与该课程 active 决议比对，相似度 ≥ 0.80 → 弹「⚠️ 这个在 11/12 已经定了：xxx。还要重新讨论吗？」，可继续或删掉该议程；
  3. 点「开始处理」→ 预处理（清洗口头禅 / 时间戳，超 12k tokens 分段）→ 召回上下文（该课程最近决议与未完成待办 top 8）→ LLM 结构化抽取 → 代码校验（人名模糊匹配花名册，不匹配标「待认领」；日期以会议日期换算校验；低置信度字段标黄）；
  4. **人工确认**：确认面板顶部是会议标题（没手填时 AI 从议题建议，标「AI 生成 · 待确认」，可改；没抽到议题则用模板标题）；其余逐条勾选 / 修改决议、待办、分歧、待定问题，全部标「AI 生成 · 待确认」；
  5. 点「确认」→ 落库（meetings / tasks / memory_items，冲突旧决议标 superseded_by）→ 建索引（embedding 入库）→ 分发：生成群消息文本，点「复制群消息」；新任务自动挂 D-3 / D-1 / 过期提醒规则。
- **空状态**：转写框为空时「开始处理」置灰，旁边给「试试示例转写」快捷填入；无历史上下文时步骤 3 显示「该课程首次会议，无历史可召回」（正常流程）。
- **错误状态**：未选课程 / 日期 → 表单校验提示；转写太短（明显不是会议记录）→ 提示确认；LLM 输出 JSON 解析失败 → 自动重试 1 次，仍失败降级为规则抽取 + 手动补（确认面板可增删改），不卡死流水线；ASR 失败（Demo 模拟）→ 提示改用粘贴文字稿；中途离开 → 提示「未确认的抽取结果不会落库」。
- **组员差异**：整个页面组员不可见 / 不可达（导航隐藏，直达 URL 提示「仅组长可新建会议」）。

## 5. `/app/meeting/[id]` 纪要详情

- **入口**：课程页纪要列表；问答引用卡片（带锚点）；流水线确认完成后跳转。
- **主操作**：
  1. 看结构化纪要：议题、决议、待办、分歧、待定问题、下次会议；
  2. 点任一条目的 evidence → 右侧 / 下方原文区滚动定位并**高亮原话片段**；
  3. 被推翻的旧决议显示 superseded 标记及「被哪次新决议替代」的链接；
  4. 复制单条或整份纪要。
- **空状态**：会议存在但某分类为空（如没有分歧）→ 该区块显示「本次会议无分歧」，不隐藏区块。
- **错误状态**：id 不存在 → 「会议不存在」+ 返回课程页；原文缺失（仅结构化数据）→ evidence 点击提示「原文未保存」，不报错。
- **组员差异**：可看全部内容与高亮；不可编辑、不可重新确认。

## 6. `/app/ask` 跨课程问答

- **入口**：侧边导航「问问上次」；拒答后的追问入口。
- **主操作**：
  1. **先选课程**（必选，硬过滤 course_id，课程之间绝不串台，含自建课程）；
  2. 输入问题 → 混合检索（向量 + BM25 → RRF top 8，默认排除 superseded）→ qwen-plus 生成 ≤120 字回答，每个结论带 [日期·类型] 出处；
  3. 点引用卡片 → 跳 `/app/meeting/[id]` 高亮 evidence；
  4. 可继续追问（保留课程上下文）。
- **空状态**：未选课程 → 输入框置灰，提示「先选一门课，答案只从这门课的记录里找」；该课程无任何纪要 → 提示「这门课还没有记录，先去新建会议」。
- **错误状态**：检索低于阈值 → 「记录里没找到」+「要不要把这个问题加到下次会议议程？」按钮（设计内拒答）；LLM 失败 → 「回答生成失败，重试」并保留检索到的原文片段兜底展示；引用冲突 → 回答按最新决议为准并说明变化（如「原来定 A，11/12 改成了 B」）。
- **组员差异**：功能完全一致，组员也能问（集体记忆共享）。

## 7. `/app/cost` 成本看板

- **入口**：侧边导航「成本」；讲解演示第 2:10 段。
- **主操作**：
  1. 看调用明细表：每次 LLM / embedding / ASR 的 model、input/output tokens、audio_seconds、cost_cny、feature、关联会议；
  2. 看汇总卡片：单次会议平均成本、单次问答平均成本；
  3. 看学期推算：按「3 门课 × 8 次会 × 200 次问答」外推单用户学期成本（对照 docs/cost-model.md）；
  4. 按 feature / 课程筛选明细。
- **空状态**：usage_log 为空 →「还没有模型调用记录，处理一次会议或问一次问题就有了」；Mock 模式下显示预置计量并标「Mock 计量 · 演示数据」。
- **错误状态**：单价表缺失 / 为 0 → 该行成本显示「单价未配置」并提示检查 config/pricing.ts；日志读取失败 → 重试按钮。
- **组员差异**：仅组长可见（成本是付费决策人的信息）。

## 8. `/app/settings` 设置

- **入口**：侧边导航「设置」；顶部身份切换下拉的「管理」入口。
- **主操作**：
  1. **课程/小组**：查看现有课程；组长填名称新建课程/小组（确定性 CRUD，不调 LLM，同名阻止）；新课程记忆从零开始，立即出现在新建会议下拉、课程页与问答选课里；
  2. **花名册**：添加成员（姓名 / 角色 / 别名）、改名、改别名、重分配组长 / 组员（确定性 CRUD，不调 LLM）；小组至少保留一名组长；改名后任务记忆条目与催办文案里的负责人名字同步更新；
  3. **提醒规则**：查看 / 开关 D-3、D-1、过期第一天三档；
  4. **身份切换**：组长 / 各组员（与顶部下拉联动）；
  5. **时间快进**：「+1 天 / +3 天 / 重置」修改 DEMO_NOW，所有风险灯与提醒基于它重算；
  6. **重置 Demo 数据**：二次确认后重跑 seed，回到演示初始状态（自建课程一并清除）。
- **空状态**：把最后一名组长降为组员 → 阻止并提示「先把别人设为组长」；其余区块均有默认值，无真空态。
- **错误状态**：新建课程同名 / 超 30 字 / 空名、成员同名 / 超 20 字 / 空名 → 接口 400 并就地提示；重置失败 → 提示手动运行 `npm run seed`；时间快进后提醒扫描失败 → 提示刷新。
- **组员差异**：组员可看「身份切换」、课程列表与花名册（只读）；新建课程/小组、编辑花名册、提醒规则、时间快进、重置全部仅组长可操作（时间快进是演示上帝视角，归组长）。

## 9. `/app/meeting/live` 会议室（v2）

- 入口：顶部「🎙 开会」、首页「即将到来的会议」→「会前准备 / 进会议室」、任务与回顾每门课的「进会议室，从这些开始」。
- 进入 → 3 秒倒计时（显示录音告知，可点「先别录」）→ 录音中（音量条、会议时间、有人说话 / 静音不上传）→ 暂停 / 继续 / 4 倍速（演示）→「结束会议，整理纪要」或自动结束倒计时 → `/app/meeting/new?from=live` 自动整理。
- 空状态：没开录时转写区提示「开录后，说的话会一句句出现在这里」；结束时没有转写会报错并回到未开始，不会进入空草稿。
- Mock 下选非演示课程：不自动开录，提示换成市场营销学。
- 麦克风：选「🎤 麦克风」→ 显示「麦克风权限：还没授权 / 已允许 / 已拒绝」→ 点「开始录音」→ 页面内同意框（先不用 / 允许使用麦克风）→ 浏览器授权框 → 允许后直接开录。拒绝 → 同一个框里显示修复步骤（我改好了，重试 / 先用演示录音 / 关闭）。已授权过的直接 3 秒倒计时开录。
- Mock 下麦克风录完：显示「录音已结束：时长、有人说话多少秒（几段）」+ 回放 + 下载 WAV +「换演示录音，体验整理纪要」，不会进入空草稿。

## 10. `/app/tasks` 任务与回顾（v2）

- 组员：我的待办卡片（做完了 / 写进度 / 卡住了 / 申请延期；待审核时可撤回；卡住时可标已解决）→ 没人认领（我来认领）→ 我做完的 → 我的任务动态。首页提醒卡片有「回复进度 →」入口。
- 组长：待我处理（确认完成 / 打回、同意延期 / 不同意、复制协调消息 / 标记已解决、复制催办、指派给…）→ 组员动态 → 回顾（每门课完成 / 进行中 / 卡住 / 待确认 + 带到下次会 + 进会议室 + 会前简报）。首页顶部「待我处理 N 件」入口。
- 空状态：组员没有待办 →「手上没有未完成的任务」；组长没有例外 →「没有要你处理的事」；课程没有遗留 →「没有遗留，下次会可以直接推进新议题」。

## 11. 新建课程（2026-11-21）

- 入口：首页「我的课程」末尾的「＋ 新建课程」卡片；纪要页、会议室课程下拉的最后一项「＋ 新建课程…」；设置页的课程/小组管理。
- 填名称 → 新建（不超过 30 字、不能重名）→ 首页卡片会跳到新课程页；下拉里会自动选中新课程。只有组长能看到这些入口，接口也只允许组长新建。
- 空状态：新课程没有纪要和任务，看板显示「拖任务到这里」，问答查不到时说「记录里没找到」，回顾卡片显示「还没开过会」。

## 12. 三门课一张表、提醒回复、成功指标（2026-11-21）

- 首页：组长看「未来 7 天 · N 门课一张表」和「组员这周的担子」，组员只看自己未来 7 天要交的；提醒卡片组长显示「复制（带回复链接）」，组员显示「回复进度 →」。
- `/r/[id]` 回复页：任务和提醒原文 → 在做，能按时交 / 做完了 / 卡住了（填原因）/ 要延期（填日期和理由）→「已告诉组长」。任务没人认领时引导去认领，已完成时提示不用回复，提醒不存在时给出入口。
- `/app/metrics`：北极星柱状图（最近 4 周，按课程分色）+ 6 张指标卡（值、目标、达标状态、定义、为什么看、数据来源）。
- 空状态：没有提醒时首页提示「组长复制时带回复链接」；没有跨课撞车时「没人这周跨课撞 DDL」；指标没有数据时显示「数据不足」。

## 组员身份差异汇总

- **看**：只见自己的任务（首页 top 5、课程看板均过滤）；纪要、问答、evidence 全组共享可见。
- **改**：只能拖自己的任务卡改状态（待认领 → 进行中 → 待审核 → 已完成）、认领待认领任务、填一句进度（更新 last_update_at，风险灯据此消黄）。
- **不能**：新建会议、新建课程/小组、确认 AI 纪要、生成简报、看成本看板、动花名册 / 提醒规则 / 时间快进 / 重置。
- 所有权限判断为确定性代码，不经过 LLM；无账号体系，身份即顶部下拉框的当前选择。
- v2：组员在看板上能看到没人认领的任务并自己认领；状态只能改成「进行中 / 待审核」，「已完成」由组长在任务与回顾里确认；卡住、申请延期在任务与回顾里操作。
