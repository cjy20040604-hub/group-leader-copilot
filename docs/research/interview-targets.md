# 访谈对象与假设验证计划

> 对应 `docs/cost-model.md` §5 的三个待验证关键假设：
> **H1 组长付费意愿** · **H2 老师为贡献度数据付费的意愿** · **H3 组员对被追踪的接受度**。
> 供后续 `/design:user-research` skill 直接取用。每类各招 5–8 人，30 分钟半结构化访谈，先问行为再问态度，不问「你会不会用」这种引导题。

## 一、组长（核心用户 / 早期付费人）

**招募画像**
- 大二三本在读，本学期至少 2 门课有小组作业，且至少在其中 1 组当组长；
- 小组 4–6 人，有过「自己整理纪要 / 追着组员要进度」的经历；
- 优先招同时并行 3 门课小组作业的「重度林晓」；避开只用过现成协作工具（Notion / 飞书）且运转良好的组——他们不是最痛的人。

**5 个访谈问题**
1. 回想最近一次组会：散会后纪要是谁整理的、花了多久、发群了吗？没整理的话后来发生了什么？
2. 上一次「开会时发现没人记得之前的结论」是什么时候？当时怎么解决的（翻聊天记录 / 问人 / 重新吵一遍）？
3. 你怎么追组员的 DDL？最近一次「到期才发现没人做」是怎么回事，你当时什么感受？
4. （现场演示 Demo 后）这三步里哪一步你最想立刻用？哪一步你觉得多余或不可信？
5. 你们小组开会是线上（有文字稿）还是在教室面对面？如果只要纪要 6.9 元一学期、要会议室实时转写 14.9 元一学期（含 8 小时），你会选哪个？自己掏还是全组 AA？什么价位你会犹豫？你现在为小组作业花过什么钱（打印 / 奶茶请客 / 会员）？

**要验证的假设**
- **H1（主）**：纪要版 6.9 元 / 专业版 14.9 元（一门课的一支小组、每学期）是否在「不用想就付」区间；真有约 7 成小组只要纪要吗；8 小时实时转写够不够、3 小时 3.9 元的加时包有人买吗；AA 是否更容易成交；体验版每学期 3 次纪要能否形成依赖再转化；送的 5 分钟实时转写能不能让在教室开会的组愿意升专业版。
- 辅助：P1–P4 的痛感排序是否和我们假设一致（纪要 > 记忆 > 催办 > 总览？）；「AI 生成 · 待确认」的确认步骤是被嫌麻烦还是被觉得安心。

## 二、组员（被动使用者 / 数据生产者）

**招募画像**
- 大二三本在读，本学期在 1–3 个小组里当普通组员（非组长）；
- 分层招募：一半是「按时交付型」，一半自认或公认「拖过 DDL / 搭过便车」——后者对追踪的抵触才是真实风险；
- 至少 2 人经历过小组互评或贡献度打分。

**5 个访谈问题**
1. 组会之后你一般怎么知道自己要干什么？有没有过「以为不是我的活」或「忘了截止时间」的情况？
2. 你现在会在群里回「收到 / 做完了」吗？如果改成在工具里拖一下卡片、写一句进度，你觉得更省事还是更烦？
3. （展示贡献度看板）如果老师能看到你每个任务的完成时间和更新记录，你第一反应是什么？会不会因此少说话、少留痕？
4. 你觉得这种记录对「认真干活的人」和「搭便车的人」分别意味着什么？你们组互评时有没有吃过说不清的亏？
5. 如果组长拉你用这个工具，什么情况下你会配合，什么情况下你会装死？

**要验证的假设**
- **H3（主）**：被追踪的接受度边界在哪——「帮我说清贡献」和「被监视」的分界线；是否会导致留痕行为失真（故意不在工具里更新），进而毁掉 B 端数据价值。
- 辅助：组员侧「改状态 + 一句进度」的轻量交互是否真的够轻；催办文案模板的语气会不会引发反感。

## 三、老师（B 端付费决策人）

**招募画像**
- 高校任课教师，所授课程含小组作业 / 项目制考核，班级规模 40–80 人；
- 优先招采用过程性评价或小组互评、且公开抱怨过「搭便车 / 互评不公」的老师；
- 至少 2 人有教改项目或课程建设经费的使用经验（知道钱从哪出、怎么报）。

**5 个访谈问题**
1. 您现在怎么给小组作业打分？组内每个人的贡献怎么区分？最近一次觉得「这个分给得不公平」是什么情况？
2. 学生交上来的过程材料（纪要、分工表）您信吗？有没有发现过事后补写的？您希望看到什么样的过程证据？
3. （展示贡献度看板）谁按时完成了什么、谁从没更新过——这个数据对您评定平时分 / 处理申诉有多大用？您担心数据被学生「刷」出来吗？
4. 如果按 5 元 / 学生 / 学期采购（60 人 300 元），这个钱能走什么经费？您个人能拍板，还是要系里 / 学院审批？大概什么流程？
5. 什么条件下您愿意先在自己一门课试一学期？试用时您最想验证的一件事是什么？

**要验证的假设**
- **H2（主）**：「过程性评价证据」是否是老师愿意掏钱的真需求；5 元 / 学生的定价与经费口子是否匹配；采购决策链和周期。
- 辅助：老师对数据真实性的信任门槛（需要组长确认 + evidence 原话是否足够）；「组长带组员用 → 老师看到看板」这条自下而上路径在老师侧是否成立（会不会反而要求强制全员使用）。
