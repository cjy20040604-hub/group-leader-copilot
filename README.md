# 组长减负 · 小组作业协作纪要工具

**帮组长把会上说的话，变成确认过的决定、有人跟进的任务，和下次会接着推进的记录。**

第一个客户：5 人小组的组长，本学期 3 门课的小组作业同时在跑。

- 在线 Demo：https://group-leader-copilot.onrender.com （免费托管，休眠后第一次打开约需 50 秒）
- 不用注册，也不用 API Key。Demo 以离线模式运行，演示数据是一个 5 人小组、三门课的一周，在线版休眠或重新部署后会自动重置。
- 用 Qoder 按 Spec 驱动搭建，初始需求见 [`qoder-quest-prompt.md`](qoder-quest-prompt.md)，迭代记录见 [`TASKS.md`](TASKS.md)。

## 产品做了什么

| 环节 | Demo 里的功能 |
|---|---|
| 会上 | 会议室进入后自动开录、实时转写；有人提议改已经定过的事，当场提醒「这事 11/12 定过了」；上次遗留逐条过 |
| 会后 | 转写整理成决定、待办、待定，日期和人名由代码校验，组长确认后才生效；也支持粘贴腾讯会议 / 飞书导出，或导入钉钉会议闪记 |
| 跟进 | 组员自己认领、更新进度、标卡住、申请延期；组长只看「待我处理」；提醒带回复链接，组员点一下就回 |
| 三门课并行 | 首页只放最紧急的 1 件事和组长自己排的会议安排；同一个组员这周跨课撞 DDL 时才提醒组长 |
| 下次会 | 自动汇总「带到下次会」；会前简报；「问问上次」按课程隔离、带出处回答，证据不够就说「记录里没找到」 |

## AI 用在哪，为什么

判断标准只有一条：**这一步需不需要听懂声音或理解语言**。需要才用 AI，不需要就写规则。

| 环节 | 谁来做 | 理由 |
|---|---|---|
| 语音转文字 | AI（qwen3-asr-flash） | 只有模型能做 |
| 转写整理成决定、待办、待定 | AI（qwen3.7-plus）+ 代码校验 | 口语要理解；日期、人名必须准 |
| 问问上次、会前简报 | AI（qwen-plus + text-embedding-v4） | 按意思查找、生成摘要；必须带出处 |
| 「这事定过了」 | 只用 embedding + 关键词规则 | 要判断语义相似，但不用生成文字 |
| 开录、认领、延期审批、提醒、风险灯、统计 | 规则 | 必须可预测、可解释，边际成本几乎为零 |
| 确认决定 | 组长 | 决定的效力来自人，AI 不能代签 |

## 成本与商业模式（摘要）

单价为阿里云百炼原价（华北2）。完整算法和全部假设见 [`docs/cost-model.md`](docs/cost-model.md)。

- **单次服务成本**：
  - 1 小时组会的文字处理约 0.065 元（抽取 0.052 + 建索引 0.008 + 简报 0.0048）；
  - 一次问答的假设上限 0.0032 元，实测 0.0011 元；
  - 贵的是转写：会议室实时转写 1 小时 0.792 元，会后上传走录音文件识别 0.288 元。
- **一组一学期**（3 门课 × 8 次会、200 次问答）：模型成本约 2.20 元，加上固定成本摊销约 4.20 元。
- **定价**：

  | 档位 | 价格 | 说明 |
  |---|---|---|
  | 体验版 | 免费 | 每月 4 次，不开录音 |
  | 专业版 | 19.9 元 / 组 / 学期 | 一人购买、全组使用，可 AA；含 10 小时录音转写 |
  | 团体购入版 | 每人每学期 5 / 4 / 3 元 | 按人数阶梯（30–99 / 100–499 / 500 人以上），学校、学院、社团统一采购 |

- **单位经济**：算上体验版用户成本、支付通道费和每月 100 元固定成本，每个付费组边际贡献约 10.56 元，38 个付费组回本；录音全走实时转写时 73 组。付费率、固定成本、用量都是假设，敏感度见成本看板。
- **谁使用，谁付钱**：
  - 使用：组长确认决定、处理例外；组员认领任务、回复进度。
  - 付钱：小组里任何一个人或 AA（付钱的人和拍板的人分开）；规模化后由机构团体购入。
- **真实接口实测**（2026-11-21，总花费约 0.15 元）：
  - 真实抽取、问答、实时转写都跑通；
  - 演示会议文字处理实测 0.0117 元，在假设上限以内；
  - 「这事定过了」的判断阈值按真实向量从 0.8 校准到 0.7。

## 质量与验证

- 单元测试 108 例（`npm test`），覆盖风险灯、日期换算、人名匹配、规则抽取、任务流转、单位经济、成功指标等。
- RAG 评估 23 题（14 道能答 + 9 道应拒答，含跨课程提问）：
  - 离线模式：检索命中 14/14，答对 14/14，拒答 9/9，串台 0；
  - 真实模型：检索命中 14/14，答对 12/14（没答对的是措辞或日期写法和要点对不上），误拒 0，拒答 9/9，串台 0。
- 每次模型调用都写 `usage_log`，成本看板上的数字来自这张表。

## 局限与下一步

- 需求和付费意愿还没经过真实用户访谈验证，计划见 [`docs/research/interview-targets.md`](docs/research/interview-targets.md)。
- 线下一台设备录音时不区分发言人。规划：散会后用百炼 paraformer-v2 说话人分离给出「说话人 0 / 1 / 2」，由组长对应到组员（方案和成本见 cost-model 3.6 节）。
- 钉钉会议导入按官方接口写好，但还没用真实企业应用联调；钉钉独立的 AI 听记 App 没有公开接口。
- 没有账号体系：身份在页面右上角切换，提醒回复链接即身份。提醒是站内通知加复制文案，没有接微信 / 短信。
- 团体购入版的管理者看板、付款人和拍板人分开、录音额度控制，目前是产品规划，Demo 里还没有。

## 技术栈与本地运行

Next.js App Router + TypeScript + Tailwind · SQLite + Drizzle · OpenAI 兼容 SDK 接阿里云百炼 · MiniSearch(BM25) + 向量检索，RRF 融合。

```bash
npm i && npm run seed && npm run dev   # 离线模式，http://localhost:3000
```

```
app/         落地页、/app 工作台、API 路由
components/  页面组件
lib/         模型网关、会议流水线、RAG、任务流转、提醒、风险灯、单位经济
config/      单价表
seed/        种子会议与离线模式的预置输出
eval/        RAG 评估集与脚本
docs/        产品、成本、架构、流程、调研文档
```
