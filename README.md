# 组长减负 · 小组作业协作纪要工具

**帮组长把会上说的话，变成确认过的决定、有人跟进的任务，和下次会接着推进的记录。**

第一个客户：5 人小组的组长，本学期 3 门课的小组作业同时在跑。

- 在线 Demo：https://group-leader-copilot.onrender.com （免费托管，休眠后第一次打开约需 50 秒）
- 不用注册，也不用 API Key。Demo 以离线模式运行，演示数据是一个 5 人小组、三门课的一周，在线版休眠或重新部署后会自动重置。
- 用 Qoder 按 Spec 驱动搭建，初始需求见 [`qoder-quest-prompt.md`](qoder-quest-prompt.md)，迭代记录见 [`TASKS.md`](TASKS.md)。

## 产品做了什么

| 环节 | Demo 里的功能 |
|---|---|
| 会上 | 会议室进入后自动开录、实时转写；有人提议改已经定过的事，当场提醒「这事 11/12 定过了」；上次遗留逐条过 |
| 会后 | 转写整理成决定、待办、待定，日期和人名由代码校验，组长确认后才生效；也支持粘贴腾讯会议 / 飞书导出，或导入钉钉会议闪记 |
| 跟进 | 组员自己认领、更新进度、标卡住、申请延期；组长只看「待我处理」；DDL 前 3 天、前 1 天和过期当天弹站内通知和浏览器通知，提醒带回复链接，组员点一下就回 |
| 三门课并行 | 每门课的小组成员和角色可以不一样；首页只放最紧急的 1 件事和组长自己排的会议安排；同一个组员这周跨课撞 DDL 时才提醒组长（别组的任务只显示日期） |
| 下次会 | 自动汇总「带到下次会」；会前简报；「问问上次」按课程隔离、带出处回答，证据不够就说「记录里没找到」 |

## AI 用在哪，为什么

判断标准只有一条：**这一步需不需要听懂声音或理解语言**。需要才用 AI，不需要就写规则。

| 环节 | 谁来做 | 理由 |
|---|---|---|
| 语音转文字 | AI（qwen3-asr-flash） | 只有模型能做 |
| 转写整理成决定、待办、待定 | AI（qwen3.7-plus）+ 代码校验 | 口语要理解；日期、人名必须准 |
| 问问上次、会前简报 | AI（qwen-plus + text-embedding-v4） | 按意思查找、生成摘要；必须带出处 |
| 「这事定过了」 | 只用 embedding + 关键词规则 | 要判断语义相似，但不用生成文字 |
| 开录、认领、延期审批、提醒、风险灯、统计 | 规则 | 必须可预测、可解释，边际成本几乎为零 |
| 确认决定 | 组长 | 决定的效力来自人，AI 不能代签 |

## 成本与商业模式（摘要）

单价为阿里云百炼原价（华北2）。完整算法和全部假设见 [`docs/cost-model.md`](docs/cost-model.md)。

- **单次服务成本**：
  - 1 小时组会的文字处理约 0.065 元（抽取 0.052 + 建索引 0.008 + 简报 0.0048）；
  - 一次问答的假设上限 0.0032 元，实测 0.0011 元；
  - 贵的是转写：会议室实时转写 1 小时 0.792 元，会后上传走录音文件识别 0.288 元。
- **计价单位是一门课的一支小组**：不同课的组员可以不一样，同一个人可以在 A 课当组长、在 B 课当组员。一支小组一学期约 8 次会、约 67 次问答，纪要和实时转写分开卖：只要纪要成本约 1.40 元（模型 0.73 + 摊销 0.67），加上 8 小时会议室实时转写约 7.74 元（转写 6.34）。
- **定价**：

  | 档位 | 价格 | 说明 |
  |---|---|---|
  | 体验版 | 0 元 | 按小组算，每组每学期 3 次纪要，送 5 分钟会议室实时转写（每位组长一次） |
  | 纪要版 | 6.9 元 / 组 / 学期 | 纪要不限次（粘贴文字稿、钉钉导入）、问答、提醒、会前简报；组里任何人买、全组用，可 AA；毛利约 80% |
  | 专业版 | 14.9 元 / 组 / 学期 | 纪要版全部 + 8 小时会议室实时转写；用完照常录音、散会后整理；毛利约 48%（按 8 小时用满） |
  | 加时包 | 3.9 元 / 3 小时 | 实时转写时长，哪档都能买；毛利约 38.5% |
  | 多组包 | 19.9 元 / 人 / 学期 | 你当组长的小组一起开通（最多 4 个），纪要不限次，每组含 2 小时会议室实时转写；带 3 个组毛利约 55% |
  | 团体购入版 | 每人每门课 5 / 4 / 3 元 | 按人数阶梯（30–99 / 100–499 / 500 人以上），老师给一门课统一开通 |

- **服务器按阿里云 ECS 真实价格算**：单个 Node 进程 + SQLite，模型都走百炼接口，一台 ECS 经济型 e 实例（2 核 2G、3M 带宽、40G 盘）就够早期使用。活动价 99 元/年、续费同价（2026-11-22 查，以控制台为准），每月 8.25 元；同配置目录价年付 906.24 元。域名和 OSS 没核实到报价，没算进来。
- **单位经济**：算上体验版小组成本和支付通道费，7 成纪要版、3 成专业版时每个付费组贡献 5.57 元，6 个付费组就盖住服务器（按目录价 55 组）。体验版送 5 分钟实时转写（每位组长一次，测算按每组 0.066 元用满算），是为了让没付费的组先体验实时字幕。体验版额度定在每学期 3 次，是因为一支小组一学期只开约 8 次会，旧的「每月 4 次」会让单门课的小组永远不用付费（专业版每组贡献会掉一半）。付费率、用量都是假设，敏感度见成本看板。
- **谁使用，谁付钱**：
  - 使用：组长确认决定、处理例外；组员认领任务、回复进度。
  - 付钱：主要是组长（带几门课的买多组包），AA 只是选项；线上开会有文字稿的组买纪要版，在教室开会的组买专业版。
  - 单月利润可能为：100 / 500 / 1,000 个付费组约 131 / 688 / 1,384 元；团体购入 10 / 50 门 60 人的课约 631 / 3,186 元。所以小组付费是获客入口，利润主要靠老师按课团体购入。付费转化低于约 4.1% 时纪要版每单都亏（送 10 分钟时约 5.1%），所以体验版只送 5 分钟实时转写，每位组长一次。
- **真实接口实测**（2026-11-21，总花费约 0.15 元）：
  - 真实抽取、问答、实时转写都跑通；
  - 演示会议文字处理实测 0.0117 元，在假设上限以内；
  - 「这事定过了」的判断阈值按真实向量从 0.8 校准到 0.7。

## 质量与验证

- 单元测试 129 例（`npm test`），覆盖风险灯、日期换算、人名匹配（含只认本组名单）、规则抽取、任务流转、单位经济（含纪要版、专业版、加时包、多组包、团体购入）、套餐额度、成功指标等。
- RAG 评估 23 题（14 道能答 + 9 道应拒答，含跨课程提问）：
  - 离线模式：检索命中 14/14，答对 14/14，拒答 9/9，串台 0；
  - 真实模型：检索命中 14/14，答对 12/14（没答对的是措辞或日期写法和要点对不上），误拒 0，拒答 9/9，串台 0。
  - 题目只有 23 道，只能说明没有明显的串台和乱答，不能当统计结论。
- 每次模型调用都写 `usage_log`，成本看板底部可以展开逐项看；上面的单次成本和回本组数由同一套单价和公式计算（`lib/unit-economics.ts`，有单测）。

## 局限与下一步

- 部署：为了用免费额度，现在放在 Render（海外）上，国内访问不够稳，录音和转写也会经过境外服务器。后续为了稳定和合规，换到阿里云内地 ECS（要先做 ICP 备案），录音存 OSS，模型继续用百炼；成本已经按 ECS 经济型 e 实例 99 元/年算进去了。
- 会议室进门 3 秒自动开录：第一次用麦克风前要先在页面里同意，倒计时期间提示「请告诉参会人正在录音」；正式版还需要每位参会人自己确认。
- 需求和付费意愿还没经过真实用户访谈验证，计划见 [`docs/research/interview-targets.md`](docs/research/interview-targets.md)。
- 线下一台设备录音时不区分发言人。规划：散会后用百炼 paraformer-v2 说话人分离给出「说话人 0 / 1 / 2」，由组长对应到组员（方案和成本见 cost-model 3.6 节）。
- 钉钉会议导入按官方接口写好，但还没用真实企业应用联调；钉钉独立的 AI 听记 App 没有公开接口。
- 没有账号体系：身份在页面右上角切换，提醒回复链接即身份。
- 提醒目前是站内弹窗加浏览器系统通知，服务端每 5 分钟定时扫描；还没接钉钉 / 企业微信群机器人（下一步，免费），不发短信（一支小组一学期最多约 72 条，短信费会超过这支小组的全部成本）。
- 套餐、付款人和 AA、体验版 3 次纪要和 5 分钟实时转写、专业版 8 小时实时转写和加时包的额度已经按规则拦截（用完照常录音、散会后整理），但开通是演示，不接支付；团体购入版的管理者看板还没做。

## 技术栈与本地运行

Next.js App Router + TypeScript + Tailwind · SQLite + Drizzle · OpenAI 兼容 SDK 接阿里云百炼 · MiniSearch(BM25) + 向量检索，RRF 融合。

```bash
npm i && npm run seed && npm run dev   # 离线模式，http://localhost:3000
```

```
app/         落地页、/app 工作台、API 路由
components/  页面组件
lib/         模型网关、会议流水线、RAG、任务流转、提醒、风险灯、单位经济
config/      单价表
seed/        种子会议与离线模式的预置输出
eval/        RAG 评估集与脚本
docs/        产品、成本、架构、流程、调研文档
```

## UI 灵感来源

落地页首屏的「纪要书架」（每本书是一场组会，颜色是课程，悬停抽出、点开翻页）参考了 [library.jjangik.kr](https://library.jjangik.kr/) 的书架式陈列。只借鉴了「把记录当成书架上的书」这个呈现方式，配色、字体和内容都是这个项目自己的。
